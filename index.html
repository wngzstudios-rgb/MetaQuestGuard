What you are licensing

A practical, layered anti-cheat stack.

The package raises the cost of client-side cheating while putting important gameplay decisions on the authoritative server.

Runtime integrity scans

Detects common mod loaders, injected libraries, instruction patching, debuggers, virtualized devices, multiple clients, and dynamic code generation.

FridaShield

Native multi-vector instrumentation checks cover ports, memory maps, threads, RWX regions, Unix sockets, ELF hashes, TracerPid, and memory tracing signals.

Native library baseline

Generate an encrypted Android native-library baseline in the Unity Editor and re-check libraries at runtime for tampering.

GorillaLocomotion-aware

Server-side validation covers arm span, grip speed, release speed, momentum decay, sustained flight, grab geometry, rubber-band teleports, and long-arm behaviour.

Generic VR validation

Validate head and hand movement, sequence monotonicity, clock skew, command rate, and other input constraints on the authoritative server.

PlayFab enforcement

Optional PlayFab CloudScript integration can send high-confidence detections to Discord and apply configurable bans when a PlayFabId is available.

Photon helpers

Includes AntiSpamRpc for RPC/instantiation rate limiting and AntiMasterClientSwitch for unauthorized Photon Master Client changes.

Mirror bridge

A thin Mirror bridge forwards validated GorillaLocomotion frames to the server-side movement validator and exposes detections to moderation hooks.

Signed reporting

Reports can be HMAC-signed when you provide a studio key. Without a key, the package can still report unsigned detection data.

Silent detection

Detection is designed around reporting and server enforcement rather than automatically quitting or quarantining the player for every signal.

Anti-false-positive thresholds

Detection thresholds are configurable per signal, with separate confidence values for movement anomalies and integrity detections.

Integration guide

Start protecting your game in three steps.

No Meta Attestation bootstrap is required. Choose anonymous scanning or connect the Guard to your own session/authentication system.

1
Add MetaQuestGuard
Place MetaQuestGuard in your scene. With allowHighValueWithoutSession enabled, runtime scanning starts automatically.
2
Connect your session or PlayFab
Optionally call SetStudioSession() with your own session data, or use the PlayFab CloudScript backend. HMAC signing is optional.
3
Validate gameplay on the server
Use ValidateInputCommand() for generic VR input or GorillaLocomotionGuard.ValidateFrame() for GorillaLocomotion-style movement. Forward detections through OnDetected.
StudioSession.cs
// No Meta Attestation required
var session = new MetaQuestGuard.StudioSession {
  SessionId = myMatchToken,
  UniqueId = myPlayerId,
  HmacKey = myOptionalHmacKey,
  TokenExpiresAtUtc = DateTime.UtcNow.AddHours(4)
};

MetaQuestGuard.Instance.SetStudioSession(session);

// Or simply allow anonymous scanning and keep enforcement server-side.
